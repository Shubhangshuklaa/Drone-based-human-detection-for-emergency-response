## Overview 🌟
A deep learning solution for detecting human presence in thermal drone imagery, designed to assist mountain rescue operations. Combines autoencoder-based anomaly detection with thermal pattern analysis for high-accuracy human identification.

**Key Features:**
- 🚨 Real-time anomaly detection
- 🔥 Thermal-specific intensity analysis
- 📊 Interactive heatmap visualization
- ⚡ Optimized for emergency response
